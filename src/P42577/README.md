## 문제
[42577 전화번호 목록](https://school.programmers.co.kr/learn/courses/30/lessons/42577)

## 풀이

### 풀이에 대한 직관적인 설명
1. 어떤 번호가 다른 번호의 접두어인지를 확인하는 문제이므로, 먼저 전화번호를 길이가 짧은 순서로 정렬합니다.

   접두어가 되는 번호는 항상 상대 번호보다 짧기 때문에, 정렬하면 접두어가 될 수 있는 번호가 먼저 나오게 됩니다.

2. 정렬된 순서대로 번호를 하나씩 보면서, 현재 번호의 접두어(길이 0부터 size-1까지)를 직접 만들어 해시맵에 있는지 확인합니다.

   예를 들어 "1195524421"이라면 "1", "11", "119", ... 순서로 접두어를 만들어 확인합니다.

3. 접두어 중 하나라도 해시맵에 있다면, 이미 본 짧은 번호가 현재 번호의 접두어라는 뜻이므로 false를 반환합니다.

4. 접두어가 하나도 없다면 현재 번호를 해시맵에 넣고 다음 번호로 넘어갑니다.

5. 모든 번호를 확인할 때까지 false가 나오지 않았다면 true를 반환합니다.

### 풀이 도출 과정
1. 모든 번호 쌍을 비교하면 O(N^2)인데, N이 최대 1,000,000이므로 시간 초과가 납니다.

   그래서 번호끼리 비교하는 대신, 번호 하나가 가질 수 있는 접두어를 해시맵으로 바로 찾는 방법을 생각했습니다.

2. 번호의 길이가 최대 20이기 때문에 번호 하나당 접두어도 최대 20개뿐입니다.

   접두어를 전부 만들어 확인해도 번호마다 상수 번의 확인만 하면 됩니다.

3. 정렬을 하는 이유는 짧은 번호가 항상 먼저 해시맵에 들어가도록 하기 위해서입니다.

   정렬하지 않으면 "1195524421"이 먼저 들어오고 "119"가 나중에 들어오는 경우를 놓치게 됩니다. 짧은 번호가 나중에 오면, 그 번호의 접두어를 확인해도 이미 들어간 긴 번호는 걸리지 않기 때문입니다.

4. 길이가 같은 번호끼리는 서로의 접두어가 될 수 없으므로(같은 번호는 중복해서 들어오지 않습니다), 길이만 기준으로 정렬하면 충분합니다.

5. 정렬 비교 함수는 문자열을 복사하지 않도록 const 참조로 받았고, 해시맵의 값은 쓰지 않고 존재 여부만 확인하기 때문에 아무 값이나 넣었습니다.

## 복잡도

* 시간복잡도 : O(N log N)

    * N = 전화번호의 개수, L = 전화번호의 길이(최대 20)

    * 길이 기준으로 정렬하는 데 O(N log N)

    * 번호마다 접두어를 최대 L개 만들고, 접두어를 만들고 해싱하는 데 O(L)씩 들기 때문에 O(N · L^2)

    * L은 최대 20인 상수이므로, 전체 시간복잡도는 정렬이 결정하는 O(N log N) 입니다.

### 사용한 언어
C++

### 사용한 소스코드
```cpp
#include <string>
#include <vector>
#include <unordered_map>
#include <algorithm>

using namespace std;

/*
phone_book의 크기가 1 이상 1,000,000 이하이므로 O(N)이여야 한다.
*/

bool compare(const string &a, const string &b) {
    return a.size() < b.size();
}

bool solution(vector<string> phone_book) {
    sort(phone_book.begin(), phone_book.end(), compare);

    unordered_map<string, bool> m;

    for(const string &str : phone_book) {
        for(int i=0; i<str.size(); i++) {
            if(m.count(str.substr(0,i))) return false;
        }
        m[str] = 1;
    }

    return true;
}
```
