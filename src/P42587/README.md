## 문제
[42587 프로세스](https://school.programmers.co.kr/learn/courses/30/lessons/42587)

## 풀이

### 풀이에 대한 직관적인 설명
1. 우선순위는 1부터 9까지밖에 없으므로, 크기가 10인 check 배열에 우선순위별로 프로세스가 몇 개 남아있는지를 세어둡니다.

2. cur는 현재 남아있는 프로세스 중 가장 높은 우선순위를 가리키는 커서로, 9에서 시작합니다.

   매번 check[cur]가 0이면 그 우선순위의 프로세스는 다 실행된 것이므로 cur를 하나씩 내려줍니다.

3. 큐를 실제로 돌리는 대신, 인덱스 i를 0부터 size-1까지 돌리고 끝에 닿으면 다시 0으로 돌아가게 해서 원형으로 순회합니다.

4. 현재 프로세스의 우선순위가 cur와 같다면 지금 남아있는 것 중 가장 높은 우선순위이므로 실행합니다.

   실행하면 check[cur]를 줄이고, 비어있는 check[0]을 지금까지 실행된 프로세스의 개수로 사용해서 1을 늘립니다.

5. 근데 만약에 방금 실행한 프로세스가 location 위치의 프로세스라면 check[0]이 곧 몇 번째로 실행됐는지이므로 바로 반환합니다.

6. 우선순위가 cur보다 낮은 프로세스는 아무것도 하지 않고 넘어가는데, 이게 큐의 맨 뒤로 다시 보내는 것과 같은 효과입니다.

### 풀이 도출 과정
1. 큐에서 하나를 꺼낼 때마다 남은 프로세스 중에 더 높은 우선순위가 있는지 전부 확인하면 번거롭습니다.

   우선순위가 1~9로 범위가 작기 때문에, 우선순위별 개수를 세어두면 가장 높은 우선순위를 바로 알 수 있다고 생각했습니다.

2. 프로세스를 뒤로 보내도 전체 순서는 그대로 원형으로 돌기 때문에, 실제로 큐에 넣고 빼지 않고 인덱스만 원형으로 돌려도 같은 순서로 확인할 수 있습니다.

3. 이미 실행된 프로세스를 따로 표시하지 않아도 되는데, cur는 한 번 내려가면 다시 올라가지 않기 때문입니다.

   우선순위가 cur인 프로세스들은 한 바퀴를 다 돌기 전에 모두 실행되고, 그러면 cur가 내려가서 이미 실행된 프로세스와 다시 같아질 일이 없습니다.

4. 우선순위는 1부터 시작해서 check[0]은 쓰이지 않는 칸이므로, 실행 횟수를 세는 변수를 따로 만들지 않고 check[0]을 사용했습니다.

## 복잡도

* 시간복잡도 : O(N)

    * 우선순위별 개수를 세는 데 O(N)

    * 같은 우선순위의 프로세스는 배열을 최대 한 바퀴 도는 동안 모두 실행되고, 우선순위는 최대 9가지이므로 순회는 최대 9N번입니다.

    * 9는 상수이므로 무시할 수 있어서, 시간복잡도는 O(N) 입니다.

### 사용한 언어
C++

### 사용한 소스코드
```cpp
#include <queue>

using namespace std;

int solution(vector<int> priorities, int location) {
    int size = priorities.size();
    int check[10] = {0,};
    int cur = 9;
    
    for(int i : priorities) check[i]++;
    
    for(int i=0; cur > 0; i++) {
        if(i==size) i %= size;
        // 커서 업데이트
        while(!check[cur]) cur--;
        
        if(priorities[i] == cur) {
            check[cur]--;
            ++check[0];
        }
        
        if(cur == priorities[i] && i == location) return check[0];
    }
}
```
